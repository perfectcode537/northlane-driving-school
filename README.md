# Northlane Driving School (demo)

A cinematic one-page demo site for a fictional driving school.

**Live:** https://perfectcode537.github.io/northlane-driving-school/

- Film-leader intro, camera HUD, chapter title cards and rolling end credits
- Three.js scenes: a town where the learner car drives the lesson route as you scroll, and a 3D car you can drag to turn
- Smooth scrolling (Lenis), scroll animation (GSAP ScrollTrigger)
- Booking form (demo only, nothing is sent)

Plain HTML, CSS and JavaScript. No build step. Run it locally with:

```
python -m http.server 5173
```
